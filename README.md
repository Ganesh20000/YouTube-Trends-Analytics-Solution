# YouTube Trends Analytics — SQL Project

## Overview
A SQL-based analytics solution engineered to examine YouTube trending video 
datasets. The project extracts top-performing channels, category-wise engagement 
trends, and content performance metrics using advanced SQL techniques.

## Tools & Technologies
- SQL (MySQL)
- Joins, CTEs, Aggregations
- Window Functions, Ranking Functions
- GitHub (Version Control)

## Key Features
- Top-performing channel identification using ranking functions
- Category-wise engagement trend analysis
- Content performance comparison across video categories
- Optimized queries reducing execution time by 40%
- Advanced use of CTEs for modular and readable query structure

## SQL Concepts Demonstrated
| Concept | Usage |
|---|---|
| JOINs | Combining channel, video, and category tables |
| CTEs | Modular query structuring for readability |
| Aggregations | COUNT, SUM, AVG for engagement metrics |
| Window Functions | RANK(), ROW_NUMBER(), DENSE_RANK() |
| Subqueries | Nested filtering and performance comparison |

## Key Insights
- Identified top 10 trending channels by total views and engagement rate
- Extracted category-wise average likes, comments, and view counts
- Ranked videos by performance within each category using window functions
- Reduced query execution time by 40% through indexing and query optimization
